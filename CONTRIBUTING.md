# Contributing

Contributions are welcome through GitHub issues and pull requests.

Please include:

1. A description of the methodological or software issue.
2. A minimal synthetic-data example that does not contain participant information.
3. The expected result and the current result.
4. Tests or a reproducible command when changing analysis logic.

Changes to statistical decision rules should cite primary methodological literature and should not convert heuristic thresholds into universal pass/fail rules.
